Aturan Remi Custom Indonesia

🎴 Aturan Khusus Set Kartu As (Ace)

  • Dilarang Pakai Joker: Kartu Joker SAMA SEKALI tidak boleh dijadikan pengganti Kartu As.
  • Set 3 Kartu As (A-A-A): Hanya dapat diletakkan di meja melds jika Anda SUDAH memiliki minimal 1 meld lain di meja.
  • Set 4 Kartu As (A-A-A-A): BISA LANGSUNG diletakkan ke meja kapan saja tanpa syarat meld meja!
  • Ace Lock Discard: Kartu As tidak bisa dibuang ke Discard Pile sebelum meletakkan meld di meja.

📥 Pengambilan Discard Pile Berdasarkan Kartu Target

Klik kartu yang ingin ditargetkan pada Discard Pile dan pilih 2+ kartu cocok di tangan:

  • Kartu Ke-1 (Atas): Ambil 1 kartu (Ke-1 dijadikan meld ke meja).
  • Kartu Ke-2: Ambil 2 kartu. Kartu Ke-2 wajib dijadikan meld ke meja, Kartu Ke-1 masuk ke tangan.
  • Kartu Ke-3: Ambil 3 kartu. Kartu Ke-3 wajib dijadikan meld ke meja, Kartu Ke-1 & Ke-2 masuk ke tangan.

📐 Kombinasi Valid (Meld)

  • ATURAN SET KELOMPOK ANGKA TIDAK BERLAKU (7-7-7 atau K-K-K dilarang).
  • Set Khusus Kartu As (Ace): Ace (15 pts) HANYA bisa dibuat Set sesama As (A-A-A / A-A-A-A).
  • Run Angka (2–10): Minimal 3 kartu berurutan kembang sama. Joker BISA digunakan.
  • Run Gambar (J-Q-K): Wajib urutan J-Q-K kembang sama. TIDAK BOLEH Pakai Joker!

💥 Mekanisme PENTUNG & Penalti Pembuang

Pemain yang membuang kartu yang menyebabkan pemain lain PENTUNG akan menerima HUKUMAN PENALTI MINUS BESAR:

  • Kartu Angka (2–10): Minus 50 Poin
  • Kartu Gambar (J, Q, K): Minus 100 Poin
  • Kartu As (Ace): Minus 150 Poin
  • Kartu Joker: Minus 250 Poin
